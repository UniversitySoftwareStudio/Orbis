# Presentation Brainstorm

One file per slide. Each file is a thinking/rehearsal aid — **not** the slide text.

Use these to decide *what to say out loud*, *how to transition*, and *what to do if asked*.

## How each file is organized

- **Goal** — the one thing this slide must land. If the audience forgets everything else, this stays.
- **Say (script seed)** — natural spoken lines, not bullets. Rehearse from these, don't read them.
- **Show / point at** — what to gesture to on the slide while talking.
- **Transition out** — the sentence that hands off to the next slide (and to the next speaker).
- **If asked** — likely questions + a tight answer.
- **Don't** — traps, overclaims, time sinks to avoid.
