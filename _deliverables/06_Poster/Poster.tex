\begin{block}{Abstract}
University academic platforms function as static record-keeping
systems, failing to proactively support students navigating
complex degree requirements. \textbf{Orbis} is an intelligent
academic support system bridging this gap using
\textbf{Artificial Intelligence} and
\textbf{Retrieval-Augmented Generation (RAG)}.

\vskip0.30cm
Core contributions:
\begin{itemize}\compactitem
  \item Organized \textbf{60,649 document chunks} into
        \textbf{125 high-quality semantic leaf nodes} via
        Shannon entropy classification and MiniBatchKMeans
  \item Extracted \textbf{178 actionable obligations} from 323
        candidates via two-pass adversarial LLM review
        (\textbf{55\% acceptance rate})
  \item Generated \textbf{176 personalized assignments} for 4
        student profiles in \textbf{59 minutes} of pipeline
        processing
\end{itemize}
\end{block}

\begin{block}{Introduction}
\textbf{The Synchronization Gap:}

Students miss critical deadlines not because information is
unavailable, but because they do not know what to search for.
Traditional Student Information Systems (SIS):
\begin{itemize}\compactitem
  \item Store data without interpreting it per student state
  \item Respond to queries but never alert proactively
  \item Apply uniform rules regardless of academic profile
\end{itemize}

\vskip0.35cm
\textbf{Orbis} shifts the academic paradigm from
\textit{static storage} to \textit{autonomous orchestration}
--- an AI agent that evaluates each student's live academic
state against institutional regulations and triggers timely,
unprompted notifications.
\end{block}

\begin{block}{Dataset}

\begin{block}{Theoretical Background}
\textbf{Shannon Entropy for URL Classification:}
$$H = -\sum_{i=1}^{n} p_i \cdot \log_2(p_i)$$
High $H$ $\Rightarrow$ semantically informative URL;
Low $H$ $\Rightarrow$ dynamic template (rejected).

\vskip0.40cm
\textbf{Cosine Similarity for Semantic Retrieval:}
$$\cos(\theta) = \frac{\mathbf{A} \cdot \mathbf{B}}%
                      {\|\mathbf{A}\| \|\mathbf{B}\|}$$
L2-normalisation converts cosine to Euclidean distance,
optimising KMeans centroid updates.

\vskip0.40cm
\textbf{MiniBatchKMeans:} $\mathcal{O}(n)$ linear clustering
over 60k+ chunks, followed by Ward HAC on centroids to
minimise within-cluster variance.

\vskip0.40cm
\textbf{Extraction Acceptance Rate:}
$$\text{Acceptance Rate} = \frac{178}{323} \approx \mathbf{55\%}$$
\end{block}

\vskip0.40cm
\textbf{Phase 2 --- Orchestrator-Led Event Pipeline:}

The centralised \texttt{EventPipelineOrchestrator} controls
three stateless worker agents:

\vskip0.20cm
\begin{center}
\begin{tabular}{ll}
  \toprule
  \textbf{Agent} & \textbf{Responsibility} \\
  \midrule
  \texttt{SearchAgent}     & Vector retrieval of regulatory chunks \\
  \texttt{ReasoningAgent}  & Per-student applicability evaluation \\
  \texttt{EventCreator}    & Normalised obligation construction \\
  \bottomrule
\end{tabular}
\end{center}

\vskip0.30cm
\textbf{Two-Pass Adversarial LLM Review:}
\begin{enumerate}\compactitem
  \item \textbf{Pass 1 --- Extraction:} Full document
        evaluation; generates candidate rules with triggers,
        deadlines, and target student roles
  \item \textbf{Pass 2 --- Adversarial Fix:} Cross-references
        original document against Pass~1 output; removes stale
        items, strengthens weak wording, captures missed
        obligations
\end{enumerate}
\end{block}

\vskip0.25cm
\textbf{Hybrid Assignment Matching --- Two Parallel Channels:}
\begin{itemize}\compactitem
  \item \textbf{SQL Path (Deterministic):} Objective thresholds
        (GPA, credit count) evaluated instantly via Python
        logic --- bypasses LLM entirely, minimising latency
  \item \textbf{Contextual Path (LLM):} Complex rules evaluated
        against student \texttt{extra\_context} JSON profile
        in parallel batches; LLM produces a human-readable
        justification per assignment
\end{itemize}

\vskip0.25cm
\textbf{Double Reranking:} Initial hybrid retrieval (keyword
$+$ vector) feeds two sequential cross-encoder reranking
passes, achieving MRR $\approx$ 0.94.
\end{block}
